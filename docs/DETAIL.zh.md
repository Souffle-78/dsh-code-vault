# 代码收藏夹

对话里出现的代码——一条命令、一份配置、一段想复用的片段——直接收起来，不用再往回翻历史。

![代码收藏夹面板：4 条收藏、语言筛选，每张卡片可复制 / 插入 / 删除](../assets/screenshot-panel.webp)

![对话里的代码块，右下角是「收藏代码块」按钮](../assets/screenshot-codeblock.webp)

## 怎么用

1. 对话里每个代码块右下角都有 **收藏代码块** 按钮（一直显示，不用悬停找）。
2. 点一下，代码就存进这台浏览器的本地存储，不上传。
3. 点左侧栏的书签图标打开面板：按代码/语言/标签搜索、打标签、复制、删除、导出/导入 JSON，或者点 **插入输入框** 把这段代码放回输入框继续改。
4. 想整理就点工具栏的 **多选**：勾选多条后能批量复制、批量加标签、批量删除（删除前二次确认）。
5. 选中 2 条以上点 **合并为新条目**，按当前列表顺序整合成一条 markdown 新收藏——可以先改标题、看预览，确认后才写入。
6. 在任何界面按 **⌘⇧K**（Windows/Linux 为 Ctrl+Shift+K）都能唤起快速插入浮层：输入即搜，↑↓ 选择，回车插入，Esc 关闭。
7. 输入框写到一半时，卡片下方的 **存草稿** 会把这段文字放进 **草稿箱**（面板顶部第二个页签），重复存同一段不会新增。
8. 草稿箱里每条都有 **移入收藏夹**：选一个文件夹，草稿就变成正式收藏，落进那个目录。
9. 左侧目录树像电脑文件夹：顶部的 **新建文件夹** / 面包屑上的 **新建子文件夹** 可以套层级；**重命名** 改名字；**删除文件夹** 只删目录，里面的子文件夹和条目自动上移到上一层。
10. 整理时可以直接把卡片拖到左侧文件夹上，也可以用卡片 **更多 ▾ → 移动到…** 在对话框里挑目标（含 **未分类**）。
11. 卡片 **更多 ▾ → 编辑** 可以直接改标题和代码：左侧行号、括号自动配对、`Enter` 自动缩进、`⌘S` 保存；下方会实时列出问题（括号没配对、JSON 无效、JS 语法错误），点一下就跳到那一行。

## 说明

- 数据存在浏览器本地（localStorage），最多 400 条（收藏 + 草稿合计）、200 个文件夹，单条最长 20 万字符。
- 草稿只在「草稿箱」出现，不参与代码块的「已收藏」判断，也不进快速插入列表。
- 同样的代码重复收藏不会产生重复条目。
- 合并出的条目语言记为 markdown，各段原语言写在围栏上。
- 合并结果超长（>20 万字符）时确认按钮会禁用，避免写坏存储。
- 面板右上角可单独切换中文 / English，不受 DSH 界面语言影响。
- 草稿以 `text` 语言入库，和其它条目一样可搜索、复制、插入。

- 卡片的标题取自代码第一行并去掉注释符（`#` / `//` / `--`），正文里不会重复这一行。
